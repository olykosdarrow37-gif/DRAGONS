# VALIRYAN FREEHOLD – Android APK

1. Create a new GitHub repository and upload **everything in this folder**
   (the hidden `.github` folder must be included).
2. Open **Actions → Build VALIRYAN FREEHOLD Android APK → Run workflow**
   (it also runs on every push to `main`).
3. After 5–8 minutes, open the finished run and download **valiryan-freehold-debug-apk** from *Artifacts*.
4. Unzip it, copy `app-debug.apk` to your phone and install it
   (allow "install unknown apps" when asked).

Edit `www/index.html`, push, and a new APK is built.
